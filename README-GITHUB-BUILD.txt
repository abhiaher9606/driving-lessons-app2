DRIVING LESSONS — BUILD APK WITHOUT ANDROID STUDIO
==================================================

FASTEST METHOD: GitHub Actions

1. Create/sign in to a GitHub account.
2. Create a NEW repository, for example: driving-lessons-app
3. Upload ALL files from this project ZIP into the repository.
   IMPORTANT: Upload the CONTENTS of this folder, including the hidden .github folder.
4. Open the repository on GitHub.
5. Click the "Actions" tab.
6. Select "Build DRIVING LESSONS APK".
7. Click "Run workflow".
8. Wait for the green check mark.
9. Open the completed workflow run.
10. Scroll to "Artifacts" and download "driving-lessons-apk".
11. Extract it and you will find app-debug.apk.
12. Send app-debug.apk to your Android phone and install it.

No Android Studio is required on the Windows PC.

If GitHub asks for permission to run workflows, allow it.

IMPORTANT:
- The debug APK is for personal installation/testing.
- For Google Play Store publication, a signed release AAB should be created later.
