DRIVING LESSONS — Android APK Project
=====================================

This project packages the driving-training manager into an Android WebView app.

IMPROVEMENTS IN THIS VERSION
-----------------------------
- DRIVING LESSONS branding
- Student management
- Driving lessons, skills, ratings and progress
- Course fee / received / pending balance
- Payment received with date, method and notes
- Student payment history
- WhatsApp progress summary including payment balance
- Monthly financial report
- Monthly payment collection report
- Expense tracking (fuel, maintenance, advertising, office, other)
- Monthly received vs expenses vs net result
- Monthly lesson count and training hours
- Overall pending student payments
- Backup / Restore including students, lessons, payments and expenses
- Offline/local phone storage

BUILD
-----
1. Open this folder in Android Studio.
2. Let Android Studio install the required SDK/build tools if prompted.
3. Build > Make Project.
4. Double-click build-apk.bat to generate the debug APK.
5. APK: app\build\outputs\apk\debug\app-debug.apk

The debug APK is for installation/testing. For Play Store, create a signed release AAB/APK.
